16 Dictionaries

Key:Value Pairs

Dictionaries are written with curly brackets, and have keys and values.

dict.py
thisdict = {
  "brand": "Ford",
  "model": "Mustang",
  "year": 1964
}
print(thisdict)
16 Features

Dictionary Characteristics

Dictionaries are ordered (as of Python 3.7), changeable, and do not allow duplicate keys.

✓Changeable: We can change, add or remove items after the dictionary has been created.
✓No Duplicates: Keys must be unique. You cannot have two "brand" keys.
16 Access Items

Using Keys

You can access the items of a dictionary by referring to its key name, inside square brackets.

access.py
x = thisdict["model"]
print(x) # Outputs: Mustang

# Changing a value
thisdict["year"] = 2018
16 Summary

Recap

✓Created with curly brackets {} using key: value pairs.
✓Access values using their key (e.g. dict["key"]).
✓Keys must be unique strings or numbers.
